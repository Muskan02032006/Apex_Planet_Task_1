# Data Dictionary – ApexPlanet Sales Dataset

| Column Name   | Data Type | Meaning                             | Business Relevance                   |
|---------------|-----------|-------------------------------------|--------------------------------------|
| Order_ID      | String    | Unique identifier for each order    | Helps track and audit transactions   |
| Order_Date    | Date      | Date when the order was placed      | Enables time-series sales analysis   |
| Customer_ID   | String    | Unique identifier for each customer | Useful for customer segmentation     |
| Customer_Name | String    | Name of the customer                | For personalization and reporting    |
| Age           | Integer   | Age of the customer                 | Supports demographic analysis        |
| Gender        | String    | Gender of the customer              | Useful for gender-based marketing    |
| City          | String    | Customer’s city                     | Enables geographic sales insights    |
| Product       | String    | Name of the product purchased       | Helps in product-level analysis      |
| Category      | String    | Product category                    | Useful for category-level performance|
| Quantity      | Integer   | Units purchased                     | Key for inventory and demand planning|
| Unit_Price    | Float     | Price per unit                      | Basis for revenue calculations       |
| Total_Sales   | Float     | Total sales value                   | Core metric for revenue tracking     |
| Age_Group     | String    | Derived age category                | Supports targeted marketing strategy |
